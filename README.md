# 跨 AI 共享个人档案

本仓库是仓库所有者的**跨 AI 共享个人档案**。不同的 AI 助手可以阅读这里的公开说明，以便在协作时对齐背景、习惯与偏好。

这里只收录所有者愿意公开、并亲自确认过的内容。当前各节下的条目都是**示例占位**，不代表真实个人事实。请用确认过的信息替换示例，或删掉不需要的条目。

变更通过 Git 提交或 Pull Request 进入本仓库，历史可追溯，也可以回退。流程见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 长期目标

## 如何更新这份档案

- 在本地修改后提交（commit），并推送到 `main`；也可以开 Pull Request 再合并。两种方式都会留下记录。
- 每次提交只改一块相关内容，并在说明里写清改了哪一节。
- 还没写完的部分用 Issues 跟踪，可加上 `todo`、`profile`、`update` 标签。
- 需要查看或撤销改动时，用提交历史里的 diff 对照，再回退到先前版本。
